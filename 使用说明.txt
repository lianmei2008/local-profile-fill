本地资料填写 · Android 辅助 APK 1.1.0（批量版）

用途
读取你导入云手机的一份本地 JSON（可包含多份资料），通过 Android 系统自动填充建议填写支持的表单；
填写时在系统建议列表中点选要使用的那份资料。
适用于 Android 8.0（API 26）及以上，目标为 eBay 原生 Android 应用（com.ebay.mobile）。
内置完全离线的测试表单。没有联网权限，无需 GeeLark API Token。
这份安装包未在真实 GeeLark 云手机或当前 eBay 页面上实测，不能保证字段兼容。

开始使用
1. 将 LocalProfileFill-1.1.0.apk 上传到云手机并安装。允许安装的操作由你在云手机中完成。
   若之前安装过 1.0.0 且用同一密钥构建，可直接覆盖安装，已导入的资料仍可继续使用。
2. 参照 profile.example.json 制作你自己的 UTF-8 JSON（顶层为资料对象数组，可放多份），再把文件上传到云手机。
   示例里的姓名、地址、邮箱和密码都是演示数据，请替换；不包含此前聊天里的真实资料。
3. 打开“本地资料填写”，点击“1 导入本地 JSON”，从系统文件选择器选中该文件。
   界面会列出已导入资料的数量和前 20 份；再次导入会替换全部旧资料。
4. 点击“2 启用系统自动填充”，在 Android 设置页面选择并启用本应用。
   Android 同时只启用一个自动填充服务，启用本应用会替换当前选择的其他服务。
5. 点击“先在离线表单中测试”，点击“显示填写建议”，在系统建议列表中选择要填入的那份资料
   （列表显示序号、姓名和邮箱）。检查姓名、邮箱等是否正确，验证码一栏应保持空白。
6. 确认云手机已从可信来源安装官方 eBay，然后回到本应用，点击“3 授权已安装的 eBay”。
   该步骤记录你当前安装版本的签名；不代表自动认证其来源。
7. 点击“4 打开 eBay”，自行进入要填写的表单，点选输入框并选择系统填写建议。
   多份资料时，系统建议列表会列出每一份（序号、姓名、邮箱），点选要使用的那份。
   某些系统需长按输入框，在菜单中选择“自动填充”。
8. 核对填入内容，再自行提交表单、接受协议并处理验证。

填写范围和兼容性
- 通过官方 AutofillService 接口提供建议，只有你选择系统建议后才填入。
- 不自动点击注册、不自动接受协议、不识别或处理验证码、不调用短信接口。
- 不读取设备身份、通讯录、短信或其他应用的私有文件。
- 不扫描本机寻找资料：文件只能由你通过系统文件选择器明确选取。
- 接受资料对象数组（最多 200 份）；单个对象也兼容。再次导入会替换全部旧资料。
- 只向你授权签名的 eBay 原生应用和内置测试表单提供建议，不支持 Chrome 等浏览器。
- 页面必须把字段暴露给 Android Autofill。若 eBay 使用自绘控件或未开放的网页表单，可能无法填写。
  内置表单能填写不代表 eBay 页面一定支持。系统没有建议时，需手动输入。
- 未识别字段、验证码、确认密码、搜索等字段保持空白，地址的州/国家下拉选项也需手动处理。
- 原生应用内的 WebView 如提供域名，仅允许 ebay.com 及其子域；其他域名不提供资料。
- 如果 eBay 签名变化，服务会停止向它提供资料。确认安装来源后再重新授权。

JSON 格式
顶层是资料对象数组；只有一份资料时写单个对象也可以（会自动当作 1 份处理）。
每份资料必填字符串：first_name、last_name、email。
每份资料可选字符串：password、phone、street、city、state、postal_code、country。
电话、邮编和国家代码都写成字符串，不能省略引号。每个值最多 512 字符，不允许换行。
一次最多 200 份资料，整个文件最多 1 MB。拒绝未知字段、嵌套对象和元素内多余列表。
密码按原样保留，其余字段去除首尾空白。
电话号码按你填写的原文输入，不自动增加国家区号。

资料存储
导入成功后，将资料用 Android Keystore AES-GCM 加密存入本应用私有目录，关闭系统备份。
没有联网权限，不记录资料日志；主界面和测试表单禁止系统截图/录屏。
密码只在需要填写时解密。云手机系统和云机服务商属于你信任的运行环境，无法由本应用隔离。
导入源 JSON 本身仍为明文，本应用不删除或修改它，请自行妥善保管。
“清除已导入资料”删除应用内保存的加密资料；不会修改原 JSON 文件。
“管理已导入资料”可逐份查看并删除某一份资料，不需要重新导入整份文件。
1.0.0 导入的单个对象加密文件仍可被 1.1.0 读取（自动视为 1 份资料），无需重新导入。

源码和重新构建
源码使用平台 Java API，不依赖 Gradle、AndroidX 或第三方库。build.py 只依赖 Python 标准库。
需要 Windows、JDK 17、Android SDK Platform 35 与 Build Tools 35.0.0。
按你的路径替换以下参数后，在 PowerShell 中运行：

python build.py --java-home 'JDK目录' --build-tools 'SDK/build-tools/35.0.0' --android-jar 'SDK/platforms/android-35/android.jar' --work-dir '独立的编译工作目录' --output 'LocalProfileFill-1.1.0.apk'

脚本会在工作目录生成本地测试用签名密钥 local-test-signing.jks，不能用于公开发行。
本次构建密钥保存在原电脑 work/android-apk-build/local-test-signing.jks，不放入源码包。
后续安装更新应继续使用同一密钥；如果换密钥，需要先卸载旧版，卸载会清除本应用的资料。
APK 为纯 Java/Dex，无本地 CPU 库，兼容性仍以云手机的 Android 系统和实际运行结果为准。
